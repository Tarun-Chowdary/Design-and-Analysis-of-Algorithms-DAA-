# 📘 Overview

This repository contains assignments, problems, and solutions for the **Design and Analysis of Algorithms (DAA)** course.  
Each assignment folder includes:

- Assignment questions
- C program implementations
- Algorithmic solutions
- PDF documents for reference

The repository is organized assignment-wise for easy navigation and understanding of different DAA concepts and problem-solving techniques.

---

# 🚀 Topics Covered

The assignments include implementations and analysis of:

- Time Complexity Analysis
- Asymptotic Notations
- Recursion
- Divide and Conquer Algorithms
- Sorting Algorithms
- Searching Algorithms
- Greedy Algorithms
- Dynamic Programming
- Backtracking
- Graph Algorithms
- Trees and Traversals
- Algorithm Optimization Techniques

# 💻 Technologies Used

- C Programming
- GCC Compiler
- Data Structures
- Algorithm Design Techniques
